# Тренажёр лексики

Klar C1 — дополнение к основному курсу немецкого. Грамматику и общий язык даёт курс, приложение тренирует **лексику своей сферы**: понимание на слух и в тексте и активное использование.

## Структура

```
Сфера (Informatik / Cybersecurity / Mathe)
 └─ Уровень (A1.2 → A2 → …)
     └─ Модуль: 16 слов
         ├─ Урок 1: 8 слов (2 блока по 4)
         ├─ Урок 2: 8 слов
         └─ Тест модуля: 16 слов, зачёт от 80 %
```

Уровень контента берётся из профиля: A1 → A1.2, A2 и выше → A2 (пока нет модулей B1+).

## Урок (10–15 минут)

Для каждого блока из 4 слов:

1. **Знакомство** — карточка: артикль (цветом), мн. число, состав композита, формы глагола, сочетание, пример с переводом, аудио.
2. **Узнать** — аудирование (слышишь слово → перевод) или значение (видишь слово → перевод).
3. **Вспомнить** — найти немецкое слово по переводу, артикль, собрать композит, пропуск с вариантами, мн. число.
4. **Использовать** — пропуск без подсказки, перевод сочетания, диктант, собрать предложение.

После двух блоков — финальный круг по всем 8 словам (типы, которых ещё не было). Ошибка добавляет новое упражнение того же уровня в конец круга, но не больше 2 раз за круг. В конце — своё предложение с проверкой через ИИ-тьютора.

## Повторение (FSRS)

| Событие | Следующий показ |
|---|---|
| Урок без ошибок | через 2 дня, стадия «Вспоминаю» |
| Урок с 1 ошибкой | через ~1.5 дня, стадия «Узнаю» |
| Урок с 2+ ошибками | завтра, стадия «Узнаю» |
| Верно в повторении | интервал растёт (FSRS), стадия +1 |
| Ошибка в повторении | через 10 минут, стадия −1 |

Стадии: Новое → Узнаю → Вспоминаю → Использую → Выучено. В повторении слово на стадии «Узнаю» получает упражнение «вспомнить», выше — «использовать». За раз повторяется не больше 20 слов.

## Как добавить модуль

1. Создать модуль в `src/content/<сфера>.ts` по образцу (16 слов, `cloze` — точная подстрока примера, `parts` в сумме дают слово).
2. Добавить его в массив `modules` в `src/content/index.ts` (порядок = порядок прохождения).
3. `npm test` — тесты контента проверят пропуски, композиты, артикли и что из каждого слова строятся все упражнения.

## Код

- `src/content/` — слова и модули.
- `src/lib/exercises.ts` — генерация и проверка упражнений (ввод прощает регистр, кавычки и `ae/oe/ue/ss` вместо умлаутов, но говорит об этом).
- `src/lib/lesson.ts` — ход урока, повторения и теста (чистые функции).
- `src/lib/srs.ts` — FSRS и стадии.
- `src/lib/learning.ts` — прогресс, применение результатов, миграция сохранений.
- `src/components/lesson/`, `src/components/screens/{lesson,words,roadmap,progress}.tsx` — интерфейс.

## Пока нет
