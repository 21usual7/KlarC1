# Тренажёр лексики

Klar C1 — дополнение к основному курсу немецкого. Грамматику и общий язык даёт курс, приложение тренирует **лексику своей сферы**: понимание на слух и в тексте, чтение и активное использование.

## Структура

```
Сфера (Informatik / Cybersecurity / Mathe)
 └─ Уровень (A1.2 → A2.1 → A2.2 → …)
     └─ Модуль: 16 слов
         ├─ Урок 1: 8 слов (2 блока по 4) + текст
         ├─ Урок 2: 8 слов + текст
         └─ Тест модуля: 16 слов, зачёт от 80 %
```

Уровень контента берётся из профиля: A1 → A1.2, A2 → A2.1, B1 и выше → A2.2 (пока нет модулей B1+). Бывший уровень A2 стал A2.1, id слов и модулей не менялись — прогресс сохраняется.

## Урок (15–20 минут)

Для каждого блока из 4 слов:

1. **Знакомство** — карточка: артикль (цветом), мн. число, состав композита, формы глагола, сочетание, пример с переводом, аудио.
2. **Узнать** — аудирование (слышишь слово → перевод), аудирование предложения (жмёшь «Прослушать» → выбираешь из 4 похожих предложений то, что прозвучало; варианты открываются после прослушивания) или значение (видишь слово → перевод).
3. **Вспомнить** — найти немецкое слово по переводу, артикль, собрать композит, пропуск с вариантами, мн. число.
4. **Использовать** — пропуск без подсказки, перевод сочетания, диктант, собрать предложение.

После двух блоков — финальный круг по всем 8 словам (типы, которых ещё не было). Ошибка добавляет новое упражнение того же уровня в конец круга, но не больше 2 раз за круг.

Затем **текст урока** (60–150 слов, сюжет на лексике урока):

1. **Чтение** — наведи курсор на слово или нажми на него, появится перевод (у формы глагола показывается и начальная форма: `melde` → `sich anmelden`). Полный перевод текста — по кнопке.
2. **Понимание** — 3–4 вопроса по тексту на немецком с вариантами и 1–2 задания на слух: звучит предложение из текста, нужно выбрать, какое. Сам текст можно прослушать целиком (обычно и медленно).

Неверные варианты в аудировании — грамматически правильные предложения: то же предложение с другим словом того же рода/окончания или другое предложение курса. Выдуманных ошибок (`Meinem Computer ist neu`) нет, чтобы глаз к ним не привыкал.
3. **Перевод предложений** — по очереди: с русского собрать немецкое предложение из плиток (есть лишние), с немецкого выбрать точный русский перевод среди «почти правильных».

Задания по тексту не влияют на FSRS и стадии слов, результат показывается в итогах урока. В конце — своё предложение с проверкой через ИИ-тьютора.

Перевод по наведению работает и в примерах на карточках и в предложениях упражнений. Источники: словарик текста (`Reading.gloss`) → слова всех модулей → общий словарь `src/content/common-words.ts`.

У каждого слова есть картинка — иконка Lucide на фоне цвета артикля (der синий, die красный, das зелёный).

## Повторение (FSRS)

| Событие | Следующий показ |
|---|---|
| Урок без ошибок | через 2 дня, стадия «Вспоминаю» |
| Урок с 1 ошибкой | через ~1.5 дня, стадия «Узнаю» |
| Урок с 2+ ошибками | завтра, стадия «Узнаю» |
| Верно в повторении | интервал растёт (FSRS), стадия +1 |
| Ошибка в повторении | через 10 минут, стадия −1 |

Стадии: Новое → Узнаю → Вспоминаю → Использую → Выучено. В повторении слово на стадии «Узнаю» получает упражнение «вспомнить», выше — «использовать». За раз повторяется не больше 20 слов.

## Как добавить модуль

1. Создать модуль по образцу (16 слов, `cloze` — точная подстрока примера, `parts` в сумме дают слово, `icon` — иконка Lucide).
2. Иконки зарегистрировать в `src/content/icons-<уровень>.ts`.
3. Добавить `readings`: по тексту на урок с `gloss`, вопросами и предложениями для перевода (см. комментарии в `src/content/types.ts`).
4. Добавить модуль в массив `modules` в `src/content/index.ts` (порядок = порядок прохождения).
5. `npm test` — тесты контента проверят пропуски, композиты, артикли, иконки, длину текстов, варианты ответов и что у каждого слова текста есть перевод по наведению.

## Код

- `src/content/` — слова, модули, тексты (`readings-*.ts`), иконки (`icons*.ts`), общий словарь.
- `src/lib/gloss.ts` — разбиение текста на слова и поиск перевода; `src/components/lesson/gloss-text.tsx` — перевод по наведению/нажатию.
- `src/lib/exercises.ts` — генерация и проверка упражнений (ввод прощает регистр, кавычки и `ae/oe/ue/ss` вместо умлаутов, но говорит об этом).
- `src/lib/lesson.ts` — ход урока, повторения и теста (чистые функции).
- `src/lib/srs.ts` — FSRS и стадии.
- `src/lib/learning.ts` — прогресс, применение результатов, миграция сохранений.
- `src/components/lesson/`, `src/components/screens/{lesson,words,roadmap,progress}.tsx` — интерфейс.

## Пока нет

Push-уведомлений (нужен PWA), справочника по грамматике, ролевых игр с ИИ по теме модуля, тестов уровня, модулей B1+.
