# Параллельная задача: требования TU Wien и учебная методика

Статус: выполнено 18 ноября 2026. Результаты: [research.md](research.md) и [methodology.md](methodology.md). Ниже сохранено исходное ТЗ исследования.

## Ожидаемый результат

Создать `docs/research.md` на русском с датой проверки и прямыми ссылками на официальные первоисточники. Код приложения и другие документы не менять, чтобы не пересекаться с текущей работой.

1. Выяснить языковые требования TU Wien к подаче документов, подготовительному этапу и началу обучения; различия по языку и уровню программы, гражданству/типу документа, если применимо. Не смешивать подтверждение немецкого с Aufnahmeverfahren.
2. Проверить каждый сертификат из ТЗ: ÖSD C1, Goethe C1, telc C1 Hochschule, TestDaF TDN 4, DSH-2. Для каждого указать: принимается ли, точные пороги/компоненты/срок действия, ссылка и оговорки. Если нельзя подтвердить — явно написать, не додумывать.
3. Собрать официальные модели экзаменов и краткую таблицу: части, длительность, типы продуктивных заданий, оценивание, доступность и права использования образцов.
4. Предложить критерии выбора основного экзамена для нашего учебного roadmap; не выбирать за пользователя без учёта его условий.
5. Дать краткий обзор доказательной базы: comprehensible input, output, retrieval practice, distributed practice, feedback и перенос в академическое использование. Отдельно отметить, что длительность сессии 45–90 минут — продуктовый выбор, а не доказанная универсальная норма.
6. Выделить необходимые изменения прототипа списком рекомендаций. Ничего не объявлять подтверждённым без источника.

Никакой отправки писем, регистрации, загрузки защищённых материалов или изменения требований приложения. Основной исполнитель сейчас работает над локальным Next.js-прототипом. Зависимости установлены; проверки приложения выполняет основной исполнитель.
