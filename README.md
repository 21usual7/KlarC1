# Klar C1

Локальный прототип платформы немецкого A1 → C1 для будущей учёбы в Вене. Next.js App Router, TypeScript, React, CSS и Lucide. Исходное задание: `prompt.txt`.

## Запуск

Требуется Node.js 22.18+ (рекомендуется 24 LTS), npm и доступ к npm registry.

```sh
npm install
npm run dev
```

Открыть http://localhost:3000. Для production: `npm run build`, затем `npm start`.

Для тьютора скопировать `.env.example` в `.env.local`, заполнить `OPENAI_API_KEY` и при необходимости `OPENAI_MODEL`, перезапустить сервер. Ключ используется только серверным маршрутом. Не коммитить `.env.local`.

## Что реализовано

- Стартовый обзор, onboarding: имя, направление, уровень, целевой экзамен и дата.
- Восемь авторских вопросов для предварительного определения A1–B2. Это не сертифицированный placement test; C1 не присваивается.
- Маршрут A1 → A2 → B1 → B2 → C1 с явными обозначениями ещё не созданных модулей.
- Две Story Immersion: A1 «Hallo, Wien!» с фразами-опорами и A2–B1 «Dein erster Tag in Wien». Подготовка, чтение/озвучивание, вопросы с объяснениями, письменное и устное задание, словарь и рефлексия. Объём письма — ориентир по уровню, а не жёсткий порог.
- Focus Mode: полноэкранный API с резервным режимом внутри страницы, таймер 20/45/60/90 минут, пауза и синтезированный фоновый шум дождя. Браузер не даёт сайту отключать системные уведомления.
- Сохранение профиля, подготовки, текста, ответов, этапа, словаря и результатов в localStorage на этом устройстве. Черновики A1 и A2–B1 независимы, старые сохранения мигрируются.
- По пять карточек в контексте каждого занятия. При успешном воспоминании интервал растёт 1 → 2 → 4 дня до 60; при ошибке карточка возвращается через 10 минут. Это простая модель, не FSRS.
- Radar и редактируемая самооценка шести навыков, журнал, вехи. Нет вымышленных баллов или результатов экзамена.
- Интерфейс тьютора с четырьмя ролями и работающим серверным маршрутом OpenAI при наличии ключа. Каждый запрос независим и содержит только отправленный текст, без истории диалога. Без ключа показывается честное сообщение об отсутствии интеграции.
- Адаптивный интерфейс, управление модальными окнами с клавиатуры, поддержка reduced motion.

## Проверка

```sh
npm test
npm run typecheck
npm run build
```

Unit tests проверяют интервалы повторения, ограничение диагностики, отдельный контент A1, защиту от дублирования результата сессии, переключение уровней, миграцию и повреждённые данные. Длительность в журнале учитывает запущенный таймер; если его не запускать, сохраняется 0 минут. Повторное завершение этой же учебной истории не создаёт второй результат.

Зависимости установлены из npm. TypeScript, 7 unit tests и production build проходят. Дополнительно проверен в Chromium сценарий A1 от начала до завершения, таймер/пауза/Focus Mode, повторение, VWU, раздельные черновики, перезагрузка и мобильная раскладка 390px. Ошибок JavaScript и горизонтальной прокрутки не обнаружено. Проверка проводилась с отдельным браузерным профилем и не меняла пользовательские данные. Локальный dev-сервер: http://localhost:3000.

## Ограничения и следующий этап

Это первый прототип, а не завершённая платформа. Нет авторизации, БД, синхронизации устройств, PWA/offline-кеша, распознавания/оценки речи, календаря, экзаменационных симуляций или адаптивной диагностики. Озвучивание зависит от установленного немецкого голоса браузера; шрифты Google необязательны, есть системные fallback-шрифты. Для сервера тьютора перед публичным размещением нужны авторизация и ограничения частоты/бюджета запросов.

Тексты авторские, не официальные материалы TU Wien. Требования и методические основания проверены отдельно: [исследование и источники](docs/research.md), [учебная методика A1–C1](docs/methodology.md). A1 — старт обучения; для рассмотренного пути подачи с иностранным аттестатом нужны признанный A2 и затем C1 к началу основной учёбы. Для уже зачисленных в VWU действует отдельная экзаменационная развилка. Условия конкретной программы: https://www.tuwien.at/en/studies/admission.

Архитектура и план развития: [docs/architecture.md](docs/architecture.md).
